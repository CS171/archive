# CS 171 archive

The CS 171 course websites and lecture slides for 2014 to 2016, served by GitHub Pages at
`https://www.cs171.org/archive/`.

- `2014/` was made with [MDWiki](http://www.mdwiki.info/) and can be edited here directly.
- `2015/`, `2016/` and `2016_Spring/` hold generated HTML only. The Jekyll source is in
  [2015-cs171-website](https://github.com/CS171/2015-cs171-website).

This repository carries the full history of the original `CS171/CS171.github.io`, which served
these sites from the root of the domain. The websites for 2017 onwards have a repository each
(`CS171/2017` and so on), and the current course website is a separate repository.
